# Widget Types

Widgets are the building blocks of a record page and of the dashboard. Each widget is placed on one or more tabs and shows data, numbers, files, events or actions.

## When to Use
Use this page to find the right widget for what you want to show. All widgets are set up on the [widget settings page](/docs/modules/widgets/widget-settings).

## Where Widgets Are Shown
- **Tiles** are shown in the top row of a tab: Count, Sum, Average, Number and Actional Button.
- **Main widgets** are shown in the grid below: all other types.

## Built-in Widget Types

| Widget | Shows | Works on |
|---|---|---|
| [Details](/docs/modules/widgets/details) | Fields of a record, optionally editable | Record pages, dashboard (with a filter) |
| [Table](/docs/modules/widgets/table) | A list of records with search, filters, views and export | Record pages, dashboard |
| [Count](/docs/modules/widgets/count) | A tile with the number of records | Record pages, dashboard |
| [Sum](/docs/modules/widgets/sum) | A tile with the total of one or more fields | Record pages, dashboard |
| [Average](/docs/modules/widgets/average) | A tile with the average of one or more fields | Record pages, dashboard |
| [Number](/docs/modules/widgets/number) | A tile adding up fields of the record the page shows | Record pages |
| [Actional Button](/docs/modules/widgets/actionalbutton) | A large button that runs an actional button | Record pages, dashboard |
| [Chart](/docs/modules/widgets/chart) | Bar, line, pie and other charts of records | Record pages, dashboard |
| [Maps](/docs/modules/widgets/maps) | Records as markers on a map, optionally with a route | Record pages, dashboard |
| [Gantt](/docs/modules/widgets/gantt) | Records as bars on a timeline, grouped by project | Record pages, dashboard |
| [Calendar](/docs/modules/widgets/calendar) | A calendar with events | Record pages, dashboard |
| [Agenda](/docs/modules/widgets/agenda) | The events of one day with a week strip | Record pages, dashboard |
| [Event Timeline](/docs/modules/widgets/calendar-timeline) | A list of events, newest first | Record pages, dashboard |
| [Files](/docs/modules/widgets/files) | Files and pictures grouped with tags, with upload and reports | Record pages, dashboard |
| [Note](/docs/modules/widgets/note) | A shared rich-text note | Record pages, dashboard |
| [Comments](/docs/modules/widgets/comments) | A comment thread | Record pages |
| [Smart Text](/docs/modules/widgets/smart-text) | Markdown text with values from the record | Record pages, dashboard |
| [Business Process](/docs/modules/widgets/business-process) | The steps of a status field | Record pages |
| [Audit History](/docs/modules/widgets/audit-history) | The change history of the record | Record pages |
| [Image](/docs/modules/widgets/image) | An image, e.g. of the record or a related record | Record pages, dashboard (with an address) |
| [Iframe](/docs/modules/widgets/iframe) | Another web page inside the widget | Record pages, dashboard |
| [Asset Booking](/docs/modules/widgets/asset-booking) | A scan field to book assets onto a project or return them | Record pages |
