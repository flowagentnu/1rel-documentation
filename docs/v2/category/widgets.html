Widgets

📄️ Widget Types

Widgets are the building blocks of a record page and of the dashboard. Each widget is placed on one or more tabs and shows data, numbers, files, events or actions.

📄️ Widget Settings

Every widget is set up on the widget settings page: Module settings → Widgets for widgets on a module's records, or Dashboard settings → Widgets for dashboard widgets. Everything a widget can do can be set up in a form, and you can switch to JSON at any time. The form and the JSON are always the same configuration.

📄️ Common Widget Properties

These settings are shared by all widgets (or by a whole group of widgets, such as all top tiles). They control the title, the look of the widget card and the buttons shown in the widget header.

📄️ Details Widget

The Details Widget shows selected fields of a record in a clear, compact layout. By default it shows the record the page is about, but it can also show a related record, for example the customer of a project. Fields can be made editable, so users can change them directly from the widget.

📄️ Table Widget

The Table Widget shows records from a module as a table. Users can search, filter, sort, choose columns, open saved views, export to Excel and print. Columns can link to records, be edited, and show coloured badges. Actional buttons can be added to the header or to every row.

📄️ Count Widget

The Count Widget is a tile in the top row that shows how many records match your filters, such as open tasks, active projects of a customer, or jobs completed today. Clicking the tile can open a tab or a web address.

📄️ Sum Widget

The Sum Widget is a tile in the top row that adds up the values of one or more fields across the records that match your filters, such as hours worked today, total sales, or the remaining budget of a project. It can also calculate with a formula, and its result can be saved into a field every night. Clicking the tile can open a tab or a web address.

📄️ Average Widget

The Average Widget is a tile in the top row that shows the average of one or more fields across the records that match your filters, such as the average order value or the average number of hours per task. It works like the Sum Widget, but divides the total by the number of records. Clicking the tile can open a tab or a web address.

📄️ Number Widget

The Number Widget is a tile in the top row that adds up one or more fields of the record the page shows, such as the hours planned plus the hours used on a project. Unlike the Sum Widget, it does not look at other records and has no filters.

📄️ ActionalButton Widget

The ActionalButton Widget shows one Actional Button as a large tile in the top row of a record page or the dashboard, so a key action is easy to find and tap.

📄️ Chart Widget

The Chart Widget shows data as a bar, line, pie, doughnut, polar area or radar chart. It can count records per value of a field (for example cases per status), show the totals of fields, or show fixed numbers, including values of the record the page shows.

📄️ Maps Widget

The Maps Widget shows records from your modules as markers on a map (OpenStreetMap). Each marker opens a popup with a link to its record. It can also mark a centre point, such as the record of the page, draw a driving route and show users' GPS positions.

📄️ Gantt Widget

The Gantt Widget shows records as bars on a timeline, from a start date to an end date. Records can be grouped by project and by another field, and each row shows how far the period has passed and how much of the work is done.

📄️ Calendar Widget

The Calendar Widget shows events in a month, week or day view and lets users create, move and edit them. Events are the appointments of the platform's calendar (including events synced from Outlook). The calendar does not show module records: there is no setting that turns a date field of a module into calendar entries. To show records on a timeline, use the Gantt Widget.

📄️ Agenda Widget

The Agenda Widget shows the calendar events of one day as a list, with a week strip above it to pick the day. It uses the same events as the Calendar Widget. When the user has a home address, it also shows the driving time and distance between the day's appointments.

📄️ Event Timeline Widget

The Event Timeline Widget shows calendar events as a vertical list, newest first, five per page. It uses the same events as the Calendar Widget, making it easy to follow the meetings and appointments of a customer or project over time.

📄️ Files Widget

The Files Widget lets users upload, view, tag and download files such as pictures and documents. Files can be uploaded from a computer (button or drag and drop) or captured with the camera on a mobile device (quick capture). The widget can also produce a PDF picture report.

📄️ Note Widget

The Note Widget lets users write and save a rich-text note with a WYSIWYG editor (bold, lists, links and so on).

📄️ Comments Widget

The Comments Widget lets users discuss a record and mention each other directly on it.

📄️ Smart Text Widget

The Smart Text Widget shows text written in Markdown, with placeholders that are filled in with values from the record, related records, the user and the date. It can show some text only when a condition is met.

📄️ Business Process Widget

The Business Process Widget shows the steps of a process as a horizontal row of steps, based on a status field of the record. Users can see at a glance which steps are done, which step the record is in now, and which steps are still ahead.

📄️ Audit History Widget

The Audit History Widget shows the change history of a record: who changed what, and when.

📄️ Image Widget

The Image Widget shows one image: by default the image of the record, or any image address you choose, for example the image of a related record or an image address stored in a field.

📄️ Iframe Widget

The Iframe Widget shows another web page inside a widget, for example a map, a report from another system or an online form.

📄️ Asset Booking Widget

The Asset Booking Widget is a scan field for tracking equipment. The user scans (or types) the code of an asset, such as a tool or a machine, and presses Enter. Depending on the widget's setting, the asset is booked onto the project the page shows, or returned to stock. The widget keeps booking records, the asset's status and the project's status up to date.

📄️ Installed Widgets

Installed widgets are widget types that come from plugins installed on your site through the Marketplace, for example a product use or registration screen built for a specific solution. They are added and set up like the built-in widgets, but their content comes from the plugin.
