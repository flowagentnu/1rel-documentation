# Widget Types

Widgets are the building blocks of a record page and of the dashboard. Each widget is placed on one or more tabs and shows data, numbers, files, events or actions.

## When to Use
Use this page to find the right widget for what you want to show. All widgets are set up on the [widget settings page](./widget-settings.md).

## Where Widgets Are Shown
- **Tiles** are shown in the top row of a tab: Count, Sum, Average, Number and Actional Button.
- **Main widgets** are shown in the grid below: all other types.

## Built-in Widget Types

| Widget | Shows | Works on |
|---|---|---|
| [Details](./details.md) | Fields of a record, optionally editable | Record pages, dashboard (with a filter) |
| [Table](./table.md) | A list of records with search, filters, views and export | Record pages, dashboard |
| [Count](./count.md) | A tile with the number of records | Record pages, dashboard |
| [Sum](./sum.md) | A tile with the total of one or more fields | Record pages, dashboard |
| [Average](./average.md) | A tile with the average of one or more fields | Record pages, dashboard |
| [Number](./number.md) | A tile adding up fields of the record the page shows | Record pages |
| [Actional Button](./actionalbutton.md) | A large button that runs an actional button | Record pages, dashboard |
| [Chart](./chart.md) | Bar, line, pie and other charts of records | Record pages, dashboard |
| [Maps](./maps.md) | Records as markers on a map, optionally with a route | Record pages, dashboard |
| [Gantt](./gantt.md) | Records as bars on a timeline, grouped by project | Record pages, dashboard |
| [Calendar](./calendar.md) | A calendar with events | Record pages, dashboard |
| [Agenda](./agenda.md) | The events of one day with a week strip | Record pages, dashboard |
| [Event Timeline](./calendar-timeline.md) | A list of events, newest first | Record pages, dashboard |
| [Files](./files.md) | Files and pictures grouped with tags, with upload and reports | Record pages, dashboard |
| [Note](./note.md) | A shared rich-text note | Record pages, dashboard |
| [Comments](./comments.md) | A comment thread | Record pages |
| [Smart Text](./smart-text.md) | Markdown text with values from the record | Record pages, dashboard |
| [Business Process](./business-process.md) | The steps of a status field | Record pages |
| [Audit History](./audit-history.md) | The change history of the record | Record pages |
| [Image](./image.md) | An image, e.g. of the record or a related record | Record pages, dashboard (with an address) |
| [Iframe](./iframe.md) | Another web page inside the widget | Record pages, dashboard |
| [Asset Booking](./asset-booking.md) | A scan field to book assets onto a project or return them | Record pages |
